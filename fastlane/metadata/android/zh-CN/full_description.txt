maripànaTokana（马拉加斯语意为"一支温度计"）是一款 Android 天气应用。它将每个数值同时以公制和英制单位并排显示，无需再换算。您也可以直接访问网页版 maripana.njarasoa.org，无需安装。

<b>天气一目了然：</b>
• 主卡片：当前天气、温度（摄氏度精确到一位小数）、今日最低和最高气温、即将到来的雨雪、空气质量不佳时的提示，以及未来 12 小时的 4 张小卡片
• 自由滚动布局：主卡片下方的其他卡片始终展开
• 逐时预报和 10 天预报，带有标签页：天气、降水、风速、气压、紫外线和空气质量，每个标签页都有概览图表
• 即将下雨或下雪时提供逐分钟预报
• 当前状况和阳光与空气小卡片：体感温度、风向罗盘和阵风、气压、湿度和露点、紫外线指数、空气质量（美国 AQI 和欧洲 AQI）、能见度、日出和日落
• 生活指数：跑步、晾晒衣物和防晒保护
• Meteocons 天气图标，分白天和夜间两种样式

<b>单位：</b>
• 每个数值都并排显示公制和英制单位
• 点按数值即可切换哪种单位显示在前

<b>天气数据和预警：</b>
• 天气数据来自 Open-Meteo（默认，无需 API 密钥）或 Pirate Weather（使用您自己的 API 密钥）
• 来自 7 个来源的天气预警：NWS、NHC、MeteoAlarm、JMA、ECCC、BOM 和 GDACS，每个来源都可以单独关闭
• 下拉即可刷新。数据过旧时应用也会自动刷新

<b>地点：</b>
• 按城市、邮政编码、坐标或 Plus Code 搜索
• 收藏地点，并左右滑动在收藏之间切换
• 地点详情卡片，显示坐标和 Plus Code

<b>语言和显示：</b>
• 8 种语言：马拉加斯语、阿拉伯语、英语、西班牙语、法语、印地语、尼泊尔语和中文。点按国旗即可切换语言
• 阿拉伯语、印地语和尼泊尔语使用本地数字
• 阿拉伯语采用从右到左的布局
• 22 种字体组合可供选择
• 可将任意卡片分享为图片
• 帮助和关于页面

<b>小部件：</b>
• 两个主屏幕小部件：紧凑型（4x1）和详细型（4x2）

<b>隐私：</b>
• 您的位置仅用于获取天气
• 无需账户，无广告，无跟踪
• 不收集任何个人数据
• 自由软件（GNU GPL 第 3 版或更高版本）
